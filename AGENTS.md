# AGENTS.md

Instructions for Cursor and other [agents.md](https://agents.md)-compatible agents in this repository.

## Always default to Snap skills

Before taking any action in this repo — planning, coding, reviewing, testing, anything — check
whether a `snap-*` skill installed by Snap already covers it, and use that skill instead of
acting ad hoc. This is the default for every task, not just feature-building.
